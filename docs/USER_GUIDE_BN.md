# GoliCoach ব্যবহার

১. “অনুশীলন শুরু করুন” চাপুন। ব্যাটিং বা বোলিং বাছুন। ১০–৩০ সেকেন্ডের MP4/WebM/MOV ভিডিও দিন (৫০ MB-এর মধ্যে)। লম্বা ভিডিও হলে শুরু ও শেষ সেকেন্ড বাছুন। পুরো শরীর, স্থির ক্যামেরা, আলো ও একজন খেলোয়াড় রাখুন। ভিডিও ব্যবহারের সম্মতি দিন; অপ্রাপ্তবয়স্ক হলে অভিভাবকের সম্মতি প্রয়োজন।

২. হাত, অভিজ্ঞতা, দৈর্ঘ্য যাচাই করুন। কী দেখতে চান তা লিখুন। “পোজ বিশ্লেষণ করুন” চাপুন। মডেল ও রানটাইম প্রথমবার লোড হবে। না চললে নিজের পর্যবেক্ষণ লিখে চালিয়ে যেতে পারবেন।

৩. পোজ, স্লো রিপ্লে ও আনুমানিক 2D কোণ দেখুন। নিজে নোট সংশোধন করুন। সেশন সংরক্ষণ করুন। JSON ডাউনলোড বা PDF → Save as PDF করুন। ভিডিও রিপোর্টে থাকে না।

“আমার সেশন” থেকে পছন্দ, ডাউনলোড, মুছুন, তুলনা করুন। একই হাত/ধরন/ক্যামেরার অবস্থানের বাস্তব সেশন তুলনা করুন। পরিবর্তন মানেই উন্নতি নয়।

অতিথি রিপোর্ট ও জার্নাল এই ব্রাউজারেই থাকে—এনক্রিপ্ট করা নয়। অন্য ডিভাইসে যাবে না। ডাউনলোড কপি রাখুন। অ্যাকাউন্ট সার্ভার যুক্ত না থাকলে লগইন ও অ্যাডমিন কাজ করবে না; UI সেটি জানাবে। নমুনা DEMO-তে AI পরিমাপ নেই।

সাধারণ ড্রিল কোচ দ্বারা যাচাইকৃত নয়। ব্যথা বা অস্বস্তি হলে থামুন। এই অ্যাপ চিকিৎসা বা চোটের পূর্বাভাস দেয় না।
